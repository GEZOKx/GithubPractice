1. Parámetros default

Un parámetro puede tener un valor por default: si quien llama a la función no le da ese argumento, se usa el valor indicado en vez de undefined.

function saludar(nombre = "invitado", mensaje = "Hola") {
  console.log(`${mensaje}, ${nombre}`);
}

saludar();              // "Hola, invitado"
saludar("Sam");         // "Hola, Sam"
saludar("Sam", "Qué tal"); // "Qué tal, Sam"

El default solo se usa si el argumento falta (o es explícitamente undefined) — si se pasa null, 0 o "", esos valores se respetan tal cual.

2. Rest params

Cuando una función debe aceptar una cantidad indefinida de argumentos, se usan los 3 puntos (...) antes del último parámetro — "junta" todo lo que sobre en un arreglo. Por eso se llama rest (lo que resta).

function sumarTodo(...numeros) {
  return numeros.reduce((total, n) => total + n, 0);
}

sumarTodo(1, 2, 3);       // 6
sumarTodo(10, 20, 30, 40); // 100

También se puede combinar con parámetros normales, siempre que el rest vaya al final:

function repartir(responsable, ...tareas) {
  console.log(`${responsable} se encarga de: ${tareas.join(", ")}`);
}

repartir("Dana", "limpiar", "cocinar", "comprar");

3. Spread

Los mismos 3 puntos (...), pero en el sentido contrario: en vez de juntar varios valores en un arreglo, expande un arreglo u objeto en sus elementos sueltos.

En llamadas a función — útil con funciones que esperan varios argumentos, no un arreglo:

const numeros = [4, 8, 15, 16, 23, 42];
Math.max(...numeros); // 42 — equivale a Math.max(4, 8, 15, 16, 23, 42)

Con arreglos — para unir varios en uno nuevo, sin mutar los originales:

const frutas = ["manzana", "pera"];
const verduras = ["zanahoria", "apio"];
const todo = [...frutas, ...verduras];
// ["manzana", "pera", "zanahoria", "apio"]

Con objetos — para combinar propiedades de varios objetos en uno nuevo. Si una propiedad se repite, gana la que está más a la derecha:

const base = { tema: "claro", idioma: "es" };
const ajustes = { idioma: "en", notificaciones: true };
const configFinal = { ...base, ...ajustes };
// { tema: "claro", idioma: "en", notificaciones: true }
Esto es la forma corta de "clonar y modificar" sin tocar el objeto original — muy común para no mutar datos que vienen de otro lado.

4. Destructuring

Permite sacar varios valores de un arreglo u objeto y guardarlos en variables, en una sola línea.

Arrays — se desestructura por posición:

const colores = ["rojo", "verde", "azul"];
const [primero, segundo, ...resto] = colores;
// primero = "rojo", segundo = "verde", resto = ["azul"]

Objetos — se desestructura por nombre de propiedad. Se puede renombrar la variable y/o darle un valor default:

const producto = { nombre: "Teclado", precio: 450 };

const { nombre, precio: costo, stock = 0 } = producto;
// nombre = "Teclado", costo = 450, stock = 0 (no existía en el objeto)

En parámetros de función — para no tener que escribir objeto.campo todo el tiempo:

function mostrarProducto({ nombre, precio }) {
  return `${nombre} cuesta $${precio}`;
}

mostrarProducto(producto); // "Teclado cuesta $450"

Se puede combinar todo: renombrar y dar default dentro de un parámetro destructurado.

5. window y el BOM EXTRA

La variable window representa la ventana del navegador, y da acceso al BOM (Browser Object Model): todo lo que tiene que ver con el navegador en sí, no con la página — su tamaño, la URL, el historial de navegación, abrir o cerrar pestañas, etc.

window.innerWidth;     // ancho de la ventana, en pixeles
window.location.href;  // la URL actual
window.open("https://www.ejemplo.com"); // abre una pestaña nueva

document (el DOM, que vemos a continuación) en realidad vive dentro de window — window.document — pero casi nadie escribe el window. porque es implícito.

Más información: MDN — Window.

6. El DOM

El DOM (Document Object Model) es la forma en la que JavaScript "ve" el HTML de una página: cada etiqueta se convierte en un objeto con el que se puede interactuar — leerlo, cambiarlo, moverlo o quitarlo. Se accede a él mediante document.

console.log(document); // todo el HTML de la página, como objeto

Para hacer algo útil con el DOM, el primer paso siempre es seleccionar el elemento con el que se quiere trabajar.

7. querySelector y querySelectorAll

Ambos reciben un selector igual que en CSS: #id, .clase, una etiqueta sola, o combinaciones más específicas.

MétodoRegresa
document.querySelector(selector)El primer elemento que coincide (o null si no hay ninguno)
document.querySelectorAll(selector)Todos los elementos que coinciden, como una lista recorrible con forEach o for...of
 
document.querySelector("#titulo");       // el elemento con id="titulo"
document.querySelector(".destacado");    // el primer elemento con class="destacado"
document.querySelectorAll("li");         // todos los <li> de la página
document.querySelectorAll(".tarjeta");   // todos los elementos con class="tarjeta"
querySelector/querySelectorAll reemplazan por completo a getElementById, getElementsByClassName y getElementsByTagName — hacen lo mismo (y más), con un solo selector tipo CSS que ya conocen.

8. textContent vs innerHTML

Una vez seleccionado un elemento, estas dos propiedades permiten leer o cambiar lo que tiene adentro.

PropiedadQué hace
textContentTrata todo como texto plano — si le asignan HTML, se muestra literal (las etiquetas no se interpretan)
innerHTMLInterpreta lo que le asignen como HTML real — crea las etiquetas que contenga
 
const parrafo = document.querySelector("p");

parrafo.textContent = "Hola <b>mundo</b>"; // se ve el texto tal cual, con las etiquetas
parrafo.innerHTML = "Hola <b>mundo</b>";   // "mundo" se ve en negritas de verdad
innerHTML es más flexible, pero si el contenido viene de un usuario (no de datos propios del programa) puede ser riesgoso — por eso textContent es la opción más segura cuando solo se necesita mostrar texto.

9. classList

classList da acceso a las clases CSS de un elemento, con métodos para agregarlas, quitarlas o alternarlas sin tener que armar el string de clases a mano.

const tarjeta = document.querySelector(".tarjeta");

tarjeta.classList.add("seleccionada");     // agrega la clase
tarjeta.classList.remove("seleccionada");  // la quita
tarjeta.classList.toggle("seleccionada");   // alterna: la pone o la quita
tarjeta.classList.contains("seleccionada"); // true/false, sin modificar nada
toggle es útil cuando un mismo botón debe "prender y apagar" algo — ahorra escribir el if que decide entre add y remove.

10. Crear e insertar elementos

createElement fabrica un elemento nuevo (todavía no está en la página), y append lo inserta dentro de otro elemento, al final.

const nuevo = document.createElement("div");
nuevo.textContent = "Soy nuevo aquí";
nuevo.classList.add("tarjeta");

const contenedor = document.querySelector("#lista");
contenedor.append(nuevo);

Un elemento recién creado con createElement no aparece en la página hasta que se inserta en algún lado con append (o similares) — se puede armar y modificar libremente antes de insertarlo.

11. Remover elementos

Para quitar un elemento de la página, ya no hace falta ir a buscar a su elemento padre — cualquier elemento sabe quitarse a sí mismo:

const tarjeta = document.querySelector(".tarjeta");
tarjeta.remove();

EXTRA Antes de que existiera .remove(), había que hacerlo desde el padre: elemento.parentElement.removeChild(elemento). Todavía se puede ver en código viejo, pero ya no hace falta escribirlo así.
