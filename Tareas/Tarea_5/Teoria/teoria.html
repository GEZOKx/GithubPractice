Teoría: CSS — colores, texto, selectores y pseudo-clases

Cómo se ve un elemento, cómo se colorea, y cómo elegir el elemento correcto para aplicarle un estilo.

Qué es CSS Colores y texto Selectores Combinadores Pseudo-clases/elementos Cascada

1. ¿Qué es CSS?

CSS (Cascading Style Sheets) describe cómo se ven los elementos HTML: color, tamaño, forma, posición. Se llama "en cascada" porque los estilos se resuelven en capas cuando hay conflictos entre reglas.

Sintaxis básica:

selector {
  propiedad: valor;
}

3 formas de incluir CSS

  • Inline: dentro del atributo style de un elemento. Mala práctica — no se comparte entre elementos.
  • Interno: con una etiqueta <style> en el <head>. No se comparte entre documentos distintos.
  • Externo: en un archivo .css aparte, enlazado con <link>. La mejor práctica — se reutiliza en todo el sitio.
<link rel="stylesheet" href="estilos.css">

2. Colores y propiedades de texto

Tipografía global (font-family)

font-family acepta una lista de opciones (font stack): el navegador usa la primera que tenga disponible. Arial, Helvetica, sans-serif es un valor que van a ver una y otra vez — es prácticamente un estándar, no algo que normalmente se inventa desde cero.

html {
  font-family: Arial, Helvetica, sans-serif;
}

Otros font-stacks comunes que van a ver en proyectos reales: Georgia, "Times New Roman", serif (serif) y "Courier New", monospace (monoespaciada, para código).

Propiedades de texto

  • text-align: alineación horizontal (left, center, right, justify).
  • letter-spacing: espacio entre letras. También existe word-spacing (espacio entre palabras).
  • font-size: tamaño del texto. px es absoluto; em/rem son relativos (más flexibles para diseño responsivo).
  • color: color del texto (no confundir con el fondo).
  • font-weight: grosor del texto — normal (400), bold (700), bolder (relativo al padre), o un número de 100 a 900.
  • text-transform: uppercase, lowercase, capitalize — cambia cómo se VE el texto sin tocar el HTML original.

Un ejemplo combinando varias:

.titulo-generico {
  text-align: right;
  letter-spacing: 1px;
  font-size: 28px;
  color: navy;
  text-transform: uppercase;
}

Colores con transparencia

background-color pinta el fondo (distinto de color, que pinta el texto). rgba(r, g, b, a) y hsla(tono, saturación, luminosidad, a) agregan un cuarto valor, alfa, la transparencia (0 = invisible, 1 = opaco).

.aviso-generico {
  background-color: rgba(0, 0, 0, 0.05);
}

El mismo efecto de transparencia también se puede lograr con hexadecimal de 8 dígitos, por ejemplo #00000010 — los últimos 2 dígitos son el alfa.

Herencia de font-weight

Muchas propiedades de texto se heredan: si un contenedor (ul, ol) define un font-weight, sus hijos (li) lo heredan a menos que ellos mismos definan otro. Lo mismo pasa con color, font-family y line-height — pero NO con border, margin ni background, que nunca se heredan.

ul { font-weight: normal; }
ol { font-weight: bold; }

3. Selectores

SelectorAplica a
h1Todos los elementos de ese tipo
.claseTodos los elementos con class="clase"
#idEl único elemento con ese id
A BTodo B dentro de A (descendiente, sin importar qué tan anidado)

Selector descendiente

Un espacio entre dos selectores significa "dentro de". Por ejemplo, .sidebar a selecciona solo los <a> que están dentro de un elemento con clase sidebar, no todos los enlaces de la página.

.sidebar a {
  text-decoration: underline;
  color: steelblue;
}

Nombres de clase e id descriptivos

Un buen nombre dice de qué es el elemento, no solo qué le pasa visualmente. .caja2 o .roja no dicen nada del contenido; .tarjeta-producto o .alerta-error sí. Lo mismo con ids: #boton1 dice poco, #formulario-enviar dice a qué componente pertenece y qué hace.

Selectores de atributo

Seleccionan elementos según un atributo HTML, sin importar la clase o el id.

SelectorSelecciona elementos cuyo atributo...
[attr^="valor"]EMPIEZA con ese valor
[attr$="valor"]TERMINA con ese valor
[attr*="valor"]CONTIENE ese valor en cualquier parte
 
img[src$=".png"] {
  border: 1px solid gray;
}

Otro uso muy común: a[target="_blank"] para marcar de forma distinta los enlaces que abren en pestaña nueva.

4. Combinadores

Los combinadores describen la relación entre dos selectores.

CombinadorSignifica
A > BB es HIJO DIRECTO de A (no nieto)
A ~ BB es cualquier hermano que aparezca DESPUÉS de A
A + BB es el hermano INMEDIATO siguiente de A
 
.menu > li {
  font-weight: bold;
}
.aviso ~ p {
  color: gray;
}
.aviso + p {
  margin-top: 0;
}

Ejemplo: en <div><p class="aviso">...</p><hr><p>...</p></div>, el <hr> en medio hace que .aviso ~ p sí aplique, pero .aviso + p no (no son adyacentes).

5. Pseudo-clases y pseudo-elementos

Una pseudo-clase (:algo) selecciona un elemento según su estado, no según su HTML.

Pseudo-claseCuándo aplica
:hoverMientras el mouse está encima
:activeMientras se hace clic
:focusMientras el elemento tiene el foco del teclado (Tab) — clave para accesibilidad
:checkedCuando un checkbox/radio está marcado
:first-child / :last-childEl primer/último hijo de su contenedor
:nth-of-type(n)El n-ésimo elemento de ese tipo dentro de su contenedor
:not(selector)Excluye los elementos que cumplen ese selector
 
#menu-lateral:hover { background-color: gainsboro; }
#panel-cerrar:active { background-color: firebrick; }
button:nth-of-type(3) { background-color: khaki; }
input[type="radio"]:checked { accent-color: purple; }

Pseudo-elementos

Un pseudo-elemento (::algo) no selecciona algo que ya existe: CREA un elemento virtual dentro del seleccionado. ::before lo inserta al inicio, ::after al final. Siempre necesitan la propiedad content (aunque sea vacío) para poder verse, y se pueden combinar con una pseudo-clase.

.tarjeta:hover::before {
  content: "→ ";
  color: gray;
}
.tarjeta:hover::after {
  content: " ←";
  color: gray;
}

::first-letter y ::first-line también son pseudo-elementos comunes — por ejemplo, para agrandar la primera letra de un artículo, como en revistas.

6. Cascada y especificidad

Cuando dos reglas le aplican al mismo elemento, gana la más específica: id > clase/atributo > tipo de elemento. Si empatan en especificidad, gana la que está escrita más abajo en el código (o la más "externa": inline > <style> > archivo externo) — salvo !important, que invierte el orden.

Algunos elementos (como los botones) no heredan color automáticamente; se puede forzar con color: inherit;.

Chrome muestra, al inspeccionar un elemento, el CSS tachado cuando una regla pierde contra otra más específica — muy útil para depurar.
